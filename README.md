# MUST Auth Website

This project uses only HTML5 and CSS3.

Files:

- `index.html` — Login page; it opens first.
- `create-account.html` — Account creation page.
- `styles.css` — Shared styling.
- `must-logo.png` — Local university logo.

To run it, open `index.html` in a browser. The Create account link uses ordinary HTML:

```html
<a href="create-account.html">Create account</a>
```

The forms are visual only; they do not save accounts.
